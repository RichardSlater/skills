# Support

## Getting help

Use GitHub issues for bugs, documentation problems, and feature requests related to this repository.

Before opening an issue:

1. Search existing issues and pull requests.
2. Read the relevant skill documentation under [`skills/`](skills/).
3. Collect non-sensitive logs, command output, and environment details.

## What to include

Please include:

- The skill or script you were using.
- The command you ran, with secrets removed.
- Expected behavior.
- Actual behavior.
- Relevant operating system, Python, and GitHub CLI versions.
- Whether the target was a GitHub organization or personal account.

## Security issues

Do not use support issues for vulnerabilities or secret exposure. Follow [`SECURITY.md`](SECURITY.md) instead.

## Secrets and private data

Do not include GitHub tokens, cloud credentials, private keys, private repository contents, or confidential organization information in public issues or pull requests.
